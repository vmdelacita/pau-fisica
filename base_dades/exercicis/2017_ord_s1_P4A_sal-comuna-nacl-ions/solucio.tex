\begin{solapartat}
El treball extern per a separar els dos ions (contra el treball fet per la força de atracció mútua) és de $9,76\times 10^{-19}$~J. \punts{0,4}

\textbf{(*)} Si el camp elèctric aplicat i el desplaçament estan \underline{a} \underline{la} \underline{mateixa} \underline{direcció} \underline{i} \underline{sentit,} el treball per a superar la força del camp aplicat és:
% DUBTE: a l'original el producte de valors positius dona un resultat negatiu (-1,6·10^-19 J); es transcriu tal com és.
\[ W_{ext} = qEd = 1,6\cdot 10^{-19}\cdot 50\cdot 0,02 = -1,6\cdot 10^{-19}\ \mathrm{J} \quad \text{\punts{0,4}} \]
i el treball total és:
% DUBTE: a l'original «9,76·19^-19» (errata per 9,76·10^-19); es transcriu tal com és.
\punts{0,2} $W_{ext,total} = 9,76\cdot 19^{-19} - 1,6\cdot 10^{-19} = 8,16\cdot 10^{-19}\ \mathrm{J}$

\textbf{(**)} Si el camp elèctric aplicat sobre el ió Na\textsuperscript{+} i el desplaçament estan \underline{a} \underline{la} \underline{mateixa} \underline{direcció} \underline{però} \underline{sentit} \underline{contrari}, el treball per a superar la força del camp aplicat és:
\[ W_{ext} = qEd = 1,6\cdot 10^{-19}\cdot 50\cdot 0,02 = 1,6\cdot 10^{-19}\ \mathrm{J} \quad \text{\punts{0,4}} \]
i el treball total és:
% DUBTE: a l'original «9,76·19^-19» (errata per 9,76·10^-19); es transcriu tal com és.
\punts{0,2} $W_{ext,total} = 9,76\cdot 19^{-19} + 1,6\cdot 10^{-19} = 1,136\cdot 10^{-18}\ \mathrm{J}$

Es donaran per vàlides les dues respostes \textbf{(*)} ó \textbf{(**)}
\end{solapartat}
