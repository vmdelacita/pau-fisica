\begin{solapartat}
De l'esquema veiem que la llargada del clarinet (L) és:
\[ L = \lambda_3 + \frac{\lambda_3}{4} = \frac{5\lambda_3}{4} \Rightarrow \lambda_3 = \frac{4L}{5} \ \text{\punts{0,4}} \]
Per altre banda:
\[ v_{so} = \lambda_3\,\nu_3 = \text{\punts{0,2}}\ \frac{4L}{5}\,\nu_3 \]
Per tan:
\[ L = \frac{5v_{so}}{4\nu_3} = \frac{5\,.\,340}{4\,.\,637} = 6,67\cdot 10^{-1}\ \mathrm{m} \ \text{\punts{0,4}} \]
\end{solapartat}

\begin{solapartat}
Si la intensitat del so augmenta el doble: $I_1 \to 2\,I_1$ Nivell de sensació sonor inicial:
\[ \beta_1 = 10\log\left(\frac{I_1}{I_0}\right)\ dB \ \text{\punts{0,4}} \]
Nou nivell de sensació sonor, al augmentar la intensitat en un factor 2:
\[ \beta_2 = 10\log\left(\frac{2I_1}{I_0}\right) = 10\log 2 + 10\log\left(\frac{I_1}{I_0}\right) = 10\log 2 + \beta_1 \ \text{\punts{0,4}} \]
\[ \Delta\beta = \beta_2 - \beta_1 = 10\log 2 = 3,01\ dB \]
Per tan el nivell de sensació sonor augmenta en $3,01\ dB$ \punts{0,2}
\end{solapartat}
