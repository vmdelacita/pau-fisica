\begin{solapartat}
Si per frenar-los calen 0,376~V, l'energia cinètica màxima serà 0,376~eV i del balanç d'energia:

\punts{0,2} $E_{C,\text{màx}} = 0,376\ \mathrm{eV} = 6,02\times 10^{-20}\ \mathrm{J}$

\punts{0,2} $E_\text{fotons} = hf = h\dfrac{c}{\lambda} = 3,64\times 10^{-19}\ \mathrm{J} = 2,27\ \mathrm{eV}$

Balanç energètic

\punts{0,4} $E_\text{fotons} = W_e + E_{C,\text{màx}}$

\punts{0,2} $W_e = E_\text{fotons} - E_{C,\text{màx}} = 3,04\times 10^{-19}\ \mathrm{J} = 1,90\ \mathrm{eV}$

\punts{0,25} I la freqüència llindar correspon a la dels fotons que tenen una energia $W_e$:
\[ f = \frac{W_e}{h} = \frac{3,04\times 10^{-19}}{6,63\times 10^{-34}} = 4,58\times 10^{14}\ \mathrm{Hz} \]
\end{solapartat}
