\begin{solapartat}
El nivell d'intensitat $\beta$ mesurat en dB es defineix com:
\begin{align*}
\beta = 10\log\frac{I}{I_0} \ \text{\punts{0,3}} &\Rightarrow 50 = 10\log\frac{I}{10^{-12}} \ \text{\punts{0,2}}\\
&\Rightarrow \frac{I}{10^{-12}} = 10^{5} \ \text{\punts{0,2}} \Rightarrow I = 10^{-7}\ \mathrm{W/m^2} \ \text{\punts{0,3}}
\end{align*}
\end{solapartat}

\begin{solapartat}
La intensitat en funció de la potència ve donada per l'expressió:
\[ I = \frac{P}{4\pi r^2} \ \text{\punts{0,3}} \Rightarrow P = 10^{-7}\,4\pi\,7^2 = 6,2\cdot 10^{-5}\ \mathrm{W} \ \text{\punts{0,2}} \]
Deixàrem de percebre el so quan la seva intensitat sigui igual a la del llindar:
\[ I = I_0 \ \text{\punts{0,3}} \Rightarrow \frac{6,2\cdot 10^{-5}}{4\pi r^2} = 10^{-12} \Rightarrow r = 2,2\cdot 10^{3}\ \mathrm{m} \]
Per tant deixarem de percebre el so a partir d'una distància de $2,2\cdot 10^{3}\ \mathrm{m}$ \punts{0,2}
\end{solapartat}
