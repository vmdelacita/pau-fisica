\begin{solapartat}
\punts{0,25} $\left|\vec{F}_e\right| = \left|k\,\dfrac{q^2}{d^2}\right|$

Condició d'equilibri:
\figura[0.18]{sol_fig1.png}

\punts{0,5} $\displaystyle \left.\begin{aligned} T\sin(15^\circ) &= k\,\frac{q^2}{d^2}\\ T\cos(15^\circ) &= mg \end{aligned}\right\} \Rightarrow \tan(15^\circ) = k\,\frac{q^2}{mg\,d^2} \Rightarrow q = d\sqrt{\tan(15^\circ)\,\frac{mg}{k}}$

\punts{0,25} $\displaystyle q = d\sqrt{\tan(15^\circ)\,\frac{mg}{k}} = 0,1\sqrt{\tan(15^\circ)\,\frac{0,02\ 9,81}{8,99\times 10^{9}}} = 2,42\times 10^{-7}\ \mathrm{C}$

\punts{0,25} $\displaystyle \left|\vec{F}\right| = \left|k\,\frac{q^2}{d^2}\right| = 8,99\times 10^{9}\,\frac{(2,42\times 10^{-7})^2}{(0,1)^2} = 5,26\times 10^{-2}\ \mathrm{N}$

\destaca{Alternativament}

\punts{0,5} $\displaystyle \left.\begin{aligned} T\sin(15^\circ) &= \left|\vec{F}_e\right|\\ T\cos(15^\circ) &= mg \end{aligned}\right\} \Rightarrow \tan(15^\circ) = \frac{\left|\vec{F}_e\right|}{mg} \Rightarrow \left|\vec{F}_e\right| = mg\tan(15^\circ)$

\punts{0,25} $\left|\vec{F}_e\right| = mg\tan(15^\circ) = 0,02\cdot 9,81\tan(15^\circ) = 5,26\times 10^{-2}\ \mathrm{N}$

\punts{0,25} $q = d\sqrt{\dfrac{\left|\vec{F}_e\right|}{k}} = 0,1\sqrt{\dfrac{5,26\times 10^{-2}}{8,99\times 10^{9}}} = 2,42\times 10^{-7}\ \mathrm{C}$
\end{solapartat}

\begin{solapartat}
Serà el mateix camp que crea la càrrega positiva:

\punts{0,5} $\left|\vec{E}\right| = \left|k\,\dfrac{q}{d^2}\right| = 8,99\times 10^{9}\,\dfrac{2,42\times 10^{-7}}{(0,1)^2} = 2,17\times 10^{5}\ \mathrm{N/C}$

\punts{0,4} La direcció és horitzontal i el sentit oposat a la força, és a dir apunta cap a la dreta:

Per altra banda, la força elèctrica té la mateixa direcció que el cas anterior però sentit oposat. \end{solapartat}
