L_\mathit{dretra} - L_\mathit{esquerra} = 10\log\frac{I_\mathit{dreta}}{I_0} - 10\log\frac{I_\mathit{esquerra}}{I_0} = \]
\[ = 10\log\frac{\dfrac{I_\mathit{dreta}}{I_0}}{\dfrac{I_\mathit{esquerra}}{I_0}} = 10\log\frac{I_\mathit{dreta}}{I_\mathit{esquerra}} = 10\log 1,06 = 0,26\ \mathrm{dB} \qquad \text{\punts{0,5}} \]
