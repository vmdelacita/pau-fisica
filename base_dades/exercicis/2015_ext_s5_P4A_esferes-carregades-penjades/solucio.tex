\begin{solapartat}
Les components $x$ del camp elèctric en $P$ s'anul·len per simetria \punts{0,2}\\
Les components $y$:

$E_y = 2E\cos 30°$ \punts{0,1} on $E = k\,\dfrac{q}{L^2} = 8,99\times 10^{9}\,\dfrac{5,8\times 10^{-6}}{1} = 52142\ \mathrm{N/C}$ \punts{0,1}

$E_y = 2\times 52142\times\cos 30° = 9,03\times 10^{4}\ \mathrm{N/C}$ \punts{0,1}

\punts{0,2} El camp elèctric total en $P$ és: $E_P = E_y$

\punts{0,1} Mòdul: $E_P = 2\times 52142\times\cos 30° = 9,03\times 10^{4}\ \mathrm{N/C}$

\punts{0,2} Direcció i sentit: vertical i cap avall.

També seria correcte expressar el camp en notació vectorial: $\vec{E}_P = (0, -9,03\times 10^{4})\ \mathrm{N/C}$\\
ó $\vec{E}_P = -9,03\times 10^{4}\,\vec{\jmath}\ \mathrm{N/C}$
\end{solapartat}
