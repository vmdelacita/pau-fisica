\begin{solapartat}
\punts{0,65} L'efecte fotoelèctric es produeix per la transferència d'energia dels fotons als electrons. Si la intensitat de llum és constant, el nombre d'electrons emesos serà el mateix, perquè el nombre de fotons que arriba a la superfície és el mateix.

Nombre d'electrons emesos: \destaca{Es manté constant}

\punts{0,6} En augmentar la freqüència dels fotons també augmenta l'energia que transfereixen als electrons i, per aquest motiu, l'energia dels electrons emesos serà més gran.

Energia dels electrons emesos: \destaca{Augmenta}
\end{solapartat}

\begin{solapartat}
\punts{0,3} Balanç d'energia: $E_C = hf - W_0 \;\Rightarrow\; W_0 = hf - E_C$

\punts{0,3} El potencial de frenada ens permet calcular l'energia necessària per aturar els electrons i, per tant, l'energia cinètica que adquireixen els electrons:
\[ E_C = e\times V_\mathrm{frenada} = 0,29\ \mathrm{eV}\,\frac{1,602\times 10^{-19}\ \mathrm{J}}{1\ \mathrm{eV}} = 4,64\times 10^{-20}\ \mathrm{J} \]

\punts{0,3} La freqüència dels fotons és:
\[ f = \frac{c}{\lambda} = \frac{3,00\times 10^{8}}{550\times 10^{-9}} = 5,45\times 10^{14}\ \mathrm{Hz} \]

\punts{0,35} I el balanç energètic dona:
\[ W_0 = hf - E_C = 3,62\times 10^{-19} - 4,64\times 10^{-20} = 3,15\times 10^{-19}\ \mathrm{J}\,\frac{1\ \mathrm{eV}}{1,602\times 10^{-19}\ \mathrm{J}} = 1,97\ \mathrm{eV} \]

O directament en eV:
\[ W_0 = hf - E_C = 3,62\times 10^{-19}\ \mathrm{J}\,\frac{1\ \mathrm{eV}}{1,602\times 10^{-19}\ \mathrm{J}} - 0,29\ \mathrm{eV} = 1,97\ \mathrm{eV} \]
\end{solapartat}
